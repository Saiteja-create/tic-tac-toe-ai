🎮 Tic Tac Toe – AI Version (Python)

This is an upgraded version of my basic Tic Tac Toe project.
In this version, I added an AI opponent that makes smarter moves based on the current state of the board.

I built this completely from scratch to practice thinking logically, handling game rules, and writing decision-making code.

💡 What I Added in the AI Version

The AI checks for winning moves

It blocks the opponent

It picks best available spots

It avoids random moves unless necessary

This made the game much more interesting compared to the basic version.

🧠 What I Learned

How to analyze a game board using code

How to make the computer pick the best move

Using functions to organize the game logic

Improving code quality compared to my first version

▶️ How to Play

Run the file using:

python tic_ai.py


You play as one player, and the AI plays against you.
